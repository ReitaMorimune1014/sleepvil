# sleepvil 絵の方針と素材一覧

要件定義の第5章「絵: 当面は四角形のプレースホルダー。本番はAI生成(不十分ならドット絵)」を進めるための資料。
「絵の方針の確定」は未決事項(第11章)。合否の最終判断は開発者(人)が行う。

## 1. 進め方
1. 下の「サンプル4点」を画像生成AIで作る
2. 「合格基準」で判定し、結果を第7章に記録する
3. 合格なら、残りの素材を同じ条件で作る。不合格ならドット絵に切り替える(同じ素材一覧を使う)
4. 素材がそろったら、Skia の図形を画像に差し替える(コード側の作業)

## 2. 画風の条件(全素材で共通)
- 2D、真横から見た絵(奥行きは重なりと大きさで出す)
- やわらかい色の、絵本のような雰囲気。夜明けの村
- 輪郭線のあり・なし、線の太さ、影の付け方を全素材でそろえる
- 光は左上から
- 背景は透過(PNG)。空はコードでグラデーションを描くので不要
- 文字やロゴを入れない

## 3. 必要な素材

座標は村の世界座標(横1200×縦600)。画像は2倍の解像度で作る。

| 種類 | 枚数 | 大きさ(px) | 備考 |
|---|---|---|---|
| 遠景(山) | 1 | 2400×800 | 横につなげても違和感がないこと |
| 中景(丘・森) | 1 | 2400×500 | 同上 |
| 地面 | 1 | 2400×440 | 上端が地面の奥の線 |
| 建物 | 7時代×5棟 = 35 | 幅180前後、高さは時代で変える | 足元を画像の下端にそろえる |
| 畑 | 2(通常・しおれ) | 300×80 | 同じ形で色だけ違う |
| 木 | 3種 | 160×240 | |
| 雲 | 3種 | 300×120 | |
| 村人 | 11コマ | 1コマ 128×128 | 待機2、歩行4、作業2、喜ぶ2、見上げる1。足元を下端にそろえる |

### 時代ごとの建物のイメージ
| 時代 | 建物の例(段階1〜5で1棟ずつ増える) |
|---|---|
| 先史 | 竪穴住居、たき火、物見やぐら、高床倉庫、石の祭壇 |
| 古代 | 石造りの家、神殿、井戸、市場の屋台、見張り塔 |
| 中世 | 木組みの家、教会、風車、城壁、小さな城 |
| 近世 | 瓦屋根の町家、蔵、茶屋、火の見やぐら、寺 |
| 近代 | れんがの家、駅舎、時計塔、工場、橋 |
| 現代 | 住宅、コンビニ、学校、ビル、公園 |
| 未来 | ドーム住宅、透明なタワー、浮かぶ庭、発着場、研究所 |

## 4. サンプル4点(最初に判定する分)
1. 先史の建物(竪穴住居)
2. 未来の建物(ドーム住宅)
3. 村人の歩行4コマ
4. 遠景(山)

先史と未来を並べて、同じ村の絵として見えるかを確かめる。

## 5. 合格基準
- [ ] 7時代の違いが、一目で分かる
- [ ] 全素材の画風(線・色・影)がそろっている
- [ ] 村人の4コマを続けて見たとき、同じ人物に見え、歩いているように見える
- [ ] スマホの画面の大きさ(建物で幅2〜3cm程度)に縮めても、形が分かる
- [ ] 背景が透過になっている(または、きれいに切り抜ける)
- [ ] 使った画像生成AIの利用規約で、App Store で配布するアプリに使ってよい
- [ ] 既存の作品やキャラクターに似すぎていない

1つでも満たせなければ、指示文を直して作り直す。2〜3回直しても満たせなければ不合格とし、ドット絵に切り替える。

## 6. 指示文の例
画像生成AIに渡す文の例。[ ] を素材ごとに入れ替える。画風の部分は全素材で同じ文を使う。

```
A 2D side-view illustration of [a prehistoric pit dwelling with a thatched roof],
for a cozy mobile game about a village at dawn.
Soft pastel colors, picture-book style, thin dark-brown outlines, light from the upper left.
Single object, centered, standing on the bottom edge, transparent background, no text.
```

村人の連続コマは、1枚の画像に横並びで描かせると、同じ人物にそろいやすい。

```
A sprite sheet of 4 frames in a row, side view of [a small villager walking to the right],
same character in every frame, soft pastel colors, picture-book style,
thin dark-brown outlines, transparent background, no text.
```
